# Contributing

Open a pull request against `main`. Explain the problem, the resulting behavior
and the validation performed. Use this module's README and `component.json` for
its supported build and test entry points.

For coordinated changes, follow the central
[PR and topic workflow](https://github.com/HypeR-Proj/ci/blob/main/docs/topic-controls.md).
That guide defines system-test requests, whole-topic submission, merge
permissions and explicit owner overrides. Keep those rules in the coordinator's
guide so repository copies cannot disagree about the active policy.

Preserve SPDX headers and third-party notices. Sign off commits with `git commit -s`.
